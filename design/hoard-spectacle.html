Spectacle with a job

Four interactions that look expensive because they're computing something real. No parallax, no confetti, nothing that would embarrass you in six months. Each one answers a question the current UI can't.

01 The Year Wall — semantic zoom

One tile per day for a year, and zoom changes what a tile is, not just its size. Zoomed out you're reading rhythm — the dead fortnight in April, the streak in July. Halfway in, tiles carry a type letter and you're reading composition. All the way in, tiles become the entries themselves. Same view, three levels of meaning, one slider.

ZOOM
Semantic zoom is the trick maps use and interfaces almost never do. It works here because a TIL log has three genuinely different readings at three scales. Render cost stays flat — tiles are divs, and above ~40px you virtualise to only what's in view.

02 Constellation — the shape of what you know

A real force simulation over your topics and entries, settling live on load. Hubs are topics sized by depth. Satellites are entries, and brightness is confidence — the things you're forgetting literally dim. Orange dashed edges are supersessions: places where you corrected yourself. Hover anything.

TOPIC HUB · SIZE = ENTRY COUNT
ENTRY · BRIGHTNESS = CONFIDENCE
SUPERSESSION EDGE
The useful read isn't the pretty part — it's the dim clusters. A topic with eight satellites all faded is a subject you researched hard and then completely lost, which no list view would ever tell you. Simulation runs ~200 ticks then freezes; re-run only on data change, never on every render.

03 Discharge — make the transfer visible

The emotional core of the whole app is debt becoming knowledge, and right now that happens silently in a database. Click DISCHARGE on a queued item: it physically leaves the queue, lands in the entry that consumed it, both counters move, and a receipt line prints. You should feel the queue getting shorter.

QUEUE · UNREAD4
TIL · TODAY1
Motion here is doing information work, not decoration: it shows which item went where. Use FLIP against real bounding boxes so it survives layout changes, keep it under 400ms, and honour prefers-reduced-motion by cross-fading counters instead.

04 Sigils — every collection gets a face

Picking an icon and colour for each collection is a chore nobody does well. Hash the name instead and generate a deterministic hard-edged sigil — mirrored, four-colour, unique per name, stable forever. Collections become recognisable at a glance in the sidebar, in share cards, and on the OG image. Type a name to generate one.

NEW COLLECTION
Deterministic from the name, so it's identical on server and client with no storage and no flash on hydration. Rename the collection and it gets a new face — which is correct, because it's a different thing now.
